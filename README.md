# PhoneX

منصة استخبارات أرقام هواتف + التقاط بصمة جهاز وموقع جغرافي عبر رابط تحقّق.

## المكوّنات

| المسار | الوصف |
|---|---|
| `phonex scan <number>` | استخبارات سلبية كاملة من الرقم (بدون تفاعل الهدف) |
| `phonex serve` | تشغيل سيرفر الالتقاط + لوحة التحكم الحيّة |
| `phonex call <number>` | إنشاء جلسة + رابط + سكربت مكالمة + متابعة حيّة |
| `phonex sessions` / `show` / `export` | إدارة الجلسات وتصدير الأدلة |
